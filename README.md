One line roasting a smart fridge, for the make.fun bounty
[Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb).

The entry:

> My fridge updated at 3 a.m. and forgot how to make ice.

The joke is the reversal: a firmware update — the smartest thing the fridge
does — breaks the dumbest, oldest job it has. The ice maker is named in the
judge brief, so the roast aims squarely at it. `main.ts` writes that single
line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
